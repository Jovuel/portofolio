DESKRIPSI SINGKAT:
Website ini adalah portofolio digital yang dibangun menggunakan HTML5, CSS3, dan framework Bootstrap 5. Website terdiri dari 4 halaman utama yang responsif (Mobile Friendly). Website ini bercerita mengenai diri saya, Jovantri Immanuel Gulo, mengenai saya, saya, dan saya.

FITUR UTAMA:
1. Halaman Utama: Hero section dengan background custom, Features grid, dan Carousel slider.
2. Halaman About: Profil diri dan Accordion untuk riwayat pendidikan/pengalaman.
3. Halaman Portfolio: Galeri karya dengan fitur Filter Kategori (Pill Tabs) dan Detail Modal (Pop-up).
4. Halaman Kontak: Formulir interaktif dengan Validasi Client-side (JavaScript), Google Maps embed, dan desain split-card modern.

CARA MEMBUKA:
1. Pastikan koneksi internet aktif (untuk memuat CDN Bootstrap).
2. Buka file 'index.html' menggunakan browser (Chrome/Edge/Firefox).
3. Apabila sudah dihosting, maka bisa juga dengan menggunakan domain yang terdaftar dan sudah dideploy.
